# مدير توصيل المطعم — الإصدار 2.0

تطبيق Android داخلي يعمل بدون إنترنت لحفظ العملاء ومواقعهم وإدارة الطلبات والسائقين.

## المزايا
- البحث الفوري برقم الجوال مع توحيد صيغ 05 و966.
- التقاط الموقع من Android مباشرة.
- حفظ بيانات العميل والعنوان والملاحظات.
- إنشاء الطلب وتعيينه لسائق.
- فتح الملاحة والاتصال وإرسال الطلب عبر واتساب.
- حالات الطلب: جديد، في الطريق، تم التسليم، ملغي.
- لوحة مؤشرات يومية.
- حساب الطلبات المسلمة والتحصيل النقدي لكل سائق.
- تصدير نسخة احتياطية ومشاركة بياناتها.

## بناء APK عبر GitHub
1. ارفع **محتويات هذا المجلد** إلى مستودع GitHub، وليس ملف ZIP نفسه.
2. افتح تبويب Actions.
3. اختر Build Android APK ثم Run workflow.
4. بعد اكتمال المهمة افتح Artifacts وحمّل RestaurantDelivery-debug-apk.

## ملاحظة المزامنة
الإصدار الحالي Offline ويحفظ البيانات على جهاز واحد. المزامنة الفورية بين جهاز المطعم وأجهزة السائقين تحتاج مشروع Firebase وإضافة ملف google-services.json ومفاتيح المشروع.
