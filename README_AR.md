# إدارة توصيل المطعم — المرحلة 3

تطبيق Android داخلي لفرع واحد وسائق واحد، يعمل عبر Firebase والإنترنت.

## المنفذ في هذه المرحلة

- تسجيل الدخول عبر Firebase Authentication.
- تحديد الواجهة تلقائيًا من `users/{uid}.role`.
- إذا لم يوجد مستند للمستخدم، يفتح التطبيق كمدير افتراضيًا.
- البحث عن العميل مباشرة من `customers/{phone}`.
- إضافة وتعديل العميل وحفظ موقعه على Firestore.
- إنشاء طلب وإرساله إلى مجموعة `orders`.
- ظهور الطلبات لحظيًا في شاشة السائق.
- حالات الطلب: جديد، تم الاستلام، في الطريق، تم التسليم، ملغي.
- فتح الملاحة في Google Maps والاتصال بالعميل.
- شاشة للمدير لمتابعة الطلبات النشطة وإلغائها.

## إعداد حساب السائق

1. من Firebase Authentication أنشئ مستخدمًا جديدًا للسائق.
2. انسخ قيمة `User UID` الخاصة به.
3. من Firestore أنشئ Collection باسم `users`.
4. أنشئ Document واجعل الـ Document ID هو UID السائق.
5. أضف الحقل:

```text
role (string) = driver
```

حساب المدير الحالي لا يحتاج مستندًا؛ سيعمل كمدير تلقائيًا. ويمكن إنشاء مستند له بقيمة `role = admin` لاحقًا.

## قواعد Firestore المطلوبة

انشر محتوى الملف:

```text
firebase/firestore.rules
```

القواعد الحالية مؤقتة وتسمح لأي مستخدم مسجل بالدخول إلى البيانات. سيتم تشديدها في مرحلة الصلاحيات النهائية.
